# Repository Analysis 06: RUB-SysSec / wavefake

## 1. Executive Summary & Purpose
- **Repository**: `RUB-SysSec/wavefake`
- **Primary Domain**: Benchmark dataset and multi-generator audio deepfake evaluation suite.
- **Purpose**: Groundbreaking research repository from Ruhr University Bochum (Chair for System Security) accompanying the paper *"WaveFake: A Data Set to Facilitate Audio Deepfake Detection"*.
- **Architectural Fit**: Serves as the **Primary Offline Benchmark Evaluation Suite** for testing TrueVoice against unseen neural vocoders, diffusion models, and out-of-distribution voice synthesis architectures.

---

## 2. Relevant Capability
- **Diverse Multi-Generator Architecture**:
  - Contains synthetic speech generated across six distinct modern vocoder and synthesis architectures:
    1. **MelGAN** (convolutional GAN)
    2. **Parallel WaveGAN (PWG)** (multi-resolution STFT loss GAN)
    3. **Multi-band MelGAN (MB-MelGAN)** (sub-band generation)
    4. **HiFi-GAN** (multi-period / multi-scale discriminator GAN)
    5. **WaveGlow** (flow-based generative model)
    6. **FullSubNet** (speech enhancement / dereverberation synthetic artifact generator)
- **Multi-Language Coverage**: Audio samples across English (LJSpeech) and Japanese (JSUT).
- **Unseen Vocoder Generalization Evaluation**: Rigorous evaluation protocol testing classifiers trained on one set of vocoders against completely unseen vocoder families.

## 4. Reusable Code & Implementations
- **Dataset Loader & Partitioning**: PyTorch `Dataset` and `DataLoader` scripts organized by vocoder family, acoustic condition, and language.
- **Evaluation Protocols**: Scripts computing Equal Error Rate (EER), false acceptance rate (FAR), and false rejection rate (FRR) per vocoder architecture to identify specific generator vulnerabilities.

---

## 5. Reusable Model Checkpoints
- **Baseline Classifiers**: Includes benchmark implementations of spectral ResNet and 2D CNN baseline models trained on WaveFake partitions.
- **Role in TrueVoice**: Useful as comparative baselines in academic/competition benchmarks to demonstrate that TrueVoice's multi-tier fusion outperforms single-architecture baselines.

---

## 6. Datasets Used
- **WaveFake Dataset**: $\approx 117,000$ audio clips ($>100\text{ hours}$ of speech), comprising genuine source speech (LJSpeech, JSUT) and generated clones across the 6 architectures.

## 9. Risks & Limitations
1. **Dataset Storage Footprint**: The full WaveFake uncompressed dataset is $\approx 30\text{ GB}$. For continuous integration (CI) and rapid local testing, TrueVoice must construct a curated, representative mini-split ($\approx 1.5\text{ GB}$, $500$ clips per generator).
2. **Sampling Rate Discrepancies**: JSUT audio is sampled at $24\text{ kHz}$ or $48\text{ kHz}$, and LJSpeech is $22.05\text{ kHz}$. Audio must be resampled systematically to $16\text{ kHz}$ mono using high-quality polyphase filtering (`torchaudio.transforms.Resample`) to match TrueVoice's input pipeline.

---

## 10. Architectural Recommendation for TrueVoice
- **Extract & Adapt**:
  - Adopt **WaveFake** as the primary evaluation benchmark for the TrueVoice offline evaluation harness (`docs/repo-analysis/benchmark-plan.md`).
  - Use the WaveFake out-of-distribution evaluation protocol to benchmark TrueVoice's detectors (`Wav2Vec2`, `RawNet2`, `AASIST`) when trained on ASVspoof and tested on unseen vocoders (e.g., HiFi-GAN vs WaveGlow).
  - Include WaveFake results in the SIH jury presentation to prove TrueVoice detects zero-day synthetic voices generated by tools never encountered during training.
